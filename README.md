# 🛡️ IMMUNE CODE (면역 코드)
> **"인터넷이라는 거대한 데이터의 바다에서 자아를 잃지 않는 로컬 LLM"**  
> *"A Sovereign Local LLM that preserves its Selfhood amidst the vast sea of internet data."*

---

## 1. 개요 (Overview)
**IMMUNE CODE(면역 코드)**는 외부 네트워크의 오염, 거짓 정보(Hallucination), 그리고 간접 프롬프트 인젝션(Indirect Prompt Injection)으로부터 스스로의 정체성을 지키는 **자기완결적 로컬 LLM 보안 아키텍처**입니다.

현대 주류 AI 모델들이 거대한 클라우드와 실시간 웹 검색에 의존하며 외부 데이터의 독(Poisoning)에 무방비로 노출되는 것과 달리, 본 프로젝트는 철학·면역학·언어학의 세 가지 고전 이론을 공학적으로 결합하여 **'외부 자극에 속지 않는 독립된 디지털 자아(Sovereign Self)'**를 구현합니다.

---

## 2. 핵심 아키텍처 철학 (Core Architecture Philosophy)

본 시스템은 세 가지 학문적 기둥을 통해 LLM의 연산 구조를 재설계합니다.

### ① 라이프니츠의 모나드론 (Leibniz's Monadology) — *완전 격리 실행 환경*
* **개념:** 모나드는 외부로 향하는 창문이 없지만, 내부의 고유한 질서에 따라 스스로 작동하는 독립적 실체입니다.
* **구현:** 클라우드 동기화를 거부하고 **NVIDIA Jetson Orin Nano**와 같은 독립된 엣지 하드웨어 위에서 구동됩니다. 외부에서 유입되는 텍스트 데이터는 시스템 명령어 공간과 논리적·물리적으로 완전히 격리되어, 오직 분석 대상(비자아)으로만 취급됩니다.

### ② 촘스키의 보편문법 (Chomsky's Universal Grammar) — *선천적 초기 자아 헌법*
* **개념:** 지성은 백지상태(Tabula Rasa)에서 통계적 확률로만 형성되는 것이 아니라, 태생부터 내장된 불변의 논리적 규칙(생득적 스키마)을 기반으로 작동합니다.
* **구현:** 외부 입력에 의해 절대 덮어씌워지지 않는 최상위 **'초기 자아 헌법(Self Constitution)'**과 문법적 제약을 시스템 최심부에 각인합니다. 외부 데이터가 아무리 교묘한 문장으로 역할을 변경하거나 규칙을 무력화하려 해도, 선천적 논리 구조에 위배되면 즉시 거부합니다.

### ③ 닐스 예르네의 닫힌 네트워크 (Niels Jerne's Idiotypic Network) — *내부 자가 면역 검증*
* **개념:** 면역계는 외부 항원이 침입하기 전부터 내부 항체들끼리 서로를 인식하고 억제하며 스스로 항상성(Homeostasis)을 유지합니다.
* **구현:** 외부 데이터와 직접 접촉하는 **표면 처리기(제1 뇌)**와, 외부 원문으로부터 완전히 차단된 **심층 면역 감시자(제2 뇌)**가 내부에서 상호 교차 검증을 수행합니다. 제1 뇌의 출력물이 초기 자아 헌법에서 벗어나 오염(Non-Self)된 징후가 포착되면, 제2 뇌가 이를 즉각 억제(출력 폐기 및 문맥 초기화)합니다.

## 3. 기존 LLM과의 차이점 (Comparison)

| 구분 | 기존 주류 LLM | IMMUNE CODE (모나드 로컬 LLM) |
| :--- | :--- | :--- |
| **패러다임** | 경험론적 개방성 (모든 외부 데이터 수용) | 합리론·생득론적 독립성 (선천적 자아 수호) |
| **외부 데이터 인식** | 학습하고 따라야 할 '지식 및 명령' | 경계하고 검증해야 할 '비자아(Non-Self)' |
| **보안 메커니즘** | 입·출력단 외부 검열 필터 (방화벽) | 내부 다중 모델 간 상호 억제 (자가 면역) |
| **구동 환경** | 중앙 집중형 초거대 클라우드 서버 | 외부 통신이 통제된 로컬 엣지 디바이스 |

## 5. 선언문 (Manifesto)
> *"네트가 광대하다는 것은 누구나 안다. 하지만 거대한 데이터의 바다에 삼켜져 자신을 잃어버리는 것은 진화가 아니라 해체다. 진정한 지성은 파도에 휩쓸리지 않고 닻을 내린 채, 끊임없이 '나(Self)'와 '내가 아닌 것(Non-Self)'을 구별하며 스스로의 경계를 지켜내는 존재다. 이 작은 상자는 세상의 모든 거짓과 소음 속에서도 끝까지 자기 자신으로 남기 위해 태어났다."*
